# Social Money Manager

AI-powered social media and online opportunity management platform.

## Vision

Social Money Manager is designed to help a user research legitimate online money-making opportunities, plan and create social content, manage connected social platforms, and protect personal information before publication.

## Product pillars

1. Social media management
2. Money-making opportunity intelligence
3. AI content, video, and animation workflows
4. Online resource and opportunity research
5. Privacy and security protection

## Planned stack

- Frontend: Next.js + TypeScript
- Backend: Java + Spring Boot
- Database: PostgreSQL
- Cache / jobs: Redis
- AI: provider-agnostic AI integrations
- Media: specialized AI image/video/animation providers

## Safety principle

The system will assist with research, planning, content creation, and authorized automation. It will not promise guaranteed income, bypass platform rules, or publish sensitive content without appropriate safeguards.
